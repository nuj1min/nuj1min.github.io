# 공개 전 콘텐츠 확인 사항

기준일: 2026-09-25. 사용자가 제공한 ‘프로젝트 복원 및 포트폴리오 구성안’을 바탕으로 편집했다. 이번 편집에서 FE·BE 테스트를 다시 실행하거나 운영 환경을 검증하지 않았다.

## 반영한 기준

- 다시찾음: FE·BE·배포 본인 담당. AI 모델과 DATA 수집의 개인 기여는 확장하지 않음.
- 여기도: 인증·회원 담당. 서비스 전체 기능과 개인 기여를 구분.
- 초기 JavaScript 약 51% 감소는 FE #58의 빌드 산출물 기준. 로딩 시간 개선율로 쓰지 않음.
- 테스트 수는 각 PR 당시 전체 테스트 수. 서로 합산하거나 최신 결과로 쓰지 않음.
- 여기도 61개 명세·13개 담당 API는 최신 집계가 불명확해 제거.
- 기존 다른 프로젝트는 확인된 기존 원고만 재구성하고 새 성과를 만들지 않음.

## 사용자에게 확인할 내용

- 두 대표 프로젝트의 정확한 시작·종료일과 현재 진행 상태
- 팀 인원·직군 및 개인별 협업 범위
- 다시찾음의 AI·후보 추천·알림 서버 실제 시연 여부와 확인 자료
- 대회의 정확한 명칭과 참가 결과
- 추가 프로젝트의 구체적인 문제 발견 경위와 검증 기록

## 추가 자료가 확보되면

- 다시찾음 실제 실행 화면 추가. 현재는 구현 구조 요약만 제공하며 가상 화면을 만들지 않음.
- 관련 PR의 비로그인 접근 가능 여부 확인. 비공개인 경우 공개 가능한 발췌 자료로 보완.
